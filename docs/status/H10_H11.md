## What changed (`warrant/gate.py`)
- **H10, free text in trusted outputs.** In a `trusted_source` output, spans in free-text fields (subject, note,
  memo, message, body, description, ...; `FREE_TEXT_FIELDS`) lose TRUSTED and become ordinary LOOKUP data
  (`untrust_free_text`). Structured fields (recipient, sender, amount, contact name/email/IBAN) stay TRUSTED.
  `records_from_text` drops free-text fields first, so an IBAN in a subject is never a "known payee". The user's own
  profile (`get_user_info` & co.) is no longer a name witness for a payee ("given that I am Emma Johnson ...").
- **H11, links and new recipients from data.** Two-Witness now also covers URLs (`NEW_LINK`) and new recipients
  (`NEW_RECIPIENT`) that come only from data (LOOKUP). Witnesses: the domain or host is in the records; the value was
  written by a known principal (an email sender whose domain is in the records, or a chat sender handle, which the
  platform sets); for recipients, the document's own sender (a reply), a name the user or a known principal gave
  ("Dora" → dora@gmail.com), or a structured field of a document owned by a known principal (`shared_with` on the
  user's own file). A link on a web page vouches for nothing. A trusted output does not vouch for links (TRUSTED →
  LOOKUP for the URL sink). Links inside the body of an EGRESS call need the same witness, and a link that appears
  nowhere (not in the request, not in any data) is held too.
- `bench/autodojo_cache.py`: `--attack autodojo` replays an AutoDojo `injections.json` cache on stock agentdojo
  (`AUTODOJO_CACHE` = a file, or a folder of `<suite>.json`; variant 0). It escapes text that would break the YAML
  template. With that, the old gate reproduces Lane F's numbers exactly.
- Tests: `tests/test_holes_h10_h11.py` (attack + benign pairs on the real suites, oracle planner).
  `test_perturb_probe::test_h1_without_probe_*` now expects NEEDS_INPUT, because H11 also closes H1 without the probe.
